# 🌱 Crop Disease Detection System Using Machine Learning

An end-to-end machine learning application that detects plant leaf diseases from images using a **Convolutional Neural Network (CNN)**. The project provides an interactive **Streamlit** interface where users can upload a leaf image, receive a disease prediction with confidence, and view recommended remedies.

---

## 📌 Overview

Crop diseases can significantly affect agricultural productivity and crop quality. Early detection can help identify diseases and support timely action.

This project applies **deep learning and computer vision** techniques to classify plant leaf images into disease categories. A CNN model is trained using the **PlantVillage dataset** and integrated into a Streamlit web application for easy and interactive prediction.

---

## 🎯 Problem Statement

Identifying crop diseases manually can be time-consuming and may require agricultural expertise. The goal of this project is to build an accessible machine learning system that can analyze plant leaf images and provide an automated disease prediction.

---

## ✨ Features

- 📊 Prediction confidence display

## 🧠 Machine Learning Approach

The system uses a **Convolutional Neural Network (CNN)** to learn visual patterns from plant leaf images and classify them into different disease categories.

## 📚 Dataset

The model was trained using the **PlantVillage dataset**, which contains images of healthy and diseased plant leaves from different crop categories.

The dataset was used to train the CNN model to recognize visual patterns associated with different plant diseases.

## 📈 Model Performance

The trained **Convolutional Neural Network (CNN)** achieved approximately **92% accuracy** on the evaluation data.

The model performance was improved through experimentation with image preprocessing and the CNN architecture.
